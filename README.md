## Mô tả dự án
Hệ thống quản lý bãi xe hỗ trợ:
- Đăng nhập & phân quyền: Quản trị viên, Nhân viên, Khách hàng
- Ghi nhận xe vào/ra, tính phí theo thời gian thực
- Quản lý vé tháng, gia hạn
- Cập nhật tức thì tình trạng ô đỗ
- Chuẩn hóa biển số, đánh dấu xe đặc biệt
- Lưu lịch sử & báo cáo hoạt động

## Hướng dẫn chạy
1. Mở `ParkingManagement.sln` bằng Visual Studio
2. Kiểm tra kết nối CSDL trong `appsettings.json`
3. Nhấn **F5** để chạy
4. Tài khoản thử:
   - Admin: `admin` / `Parking@123`
   - Nhân viên: `staff01` / `Parking@123`
   - Khách hàng: `customer (Thu01)` / `Thu@123456`
